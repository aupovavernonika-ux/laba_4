##  Описание частей работы

### 1. ЛР 4_1: Гипотезы (Датасет «Пренатальная диагностика»)
**Цель:** Проверить данные о новорождённых на нормальность и выявить гендерные различия.
**Что сделано:**
*   Загружен и изучен датасет (1050 записей).
*   Добавлен и рассчитан столбец ИМТ (с конвертацией веса из граммов в килограммы).
*   Проведен расчет описательных статистик (среднее, медиана, размах и т.д.).
*   Написана функция `Gauss` для комплексной проверки на нормальность (гистограмма, KDE, асимметрия, эксцесс, критерий хи-квадрат Пирсона).
*   Проведен анализ гендерных различий по росту, весу и ИМТ с помощью t-теста (с предварительной проверкой дисперсий критерием Левена и выбором между тестом Стьюдента и Уэлча).
*   Выполнен этап Data Cleaning (обнаружение и устранение ошибки с единицами измерения).

### 2. ЛР 4_2: T-тесты (Датасет «Психологи»)
**Цель:** Оценить наличие гендерных различий по психологическим показателям.
**Что сделано:**
*   Загружен датасет, проведена очистка названий столбцов от лишних пробелов (`str.strip()`).
*   Сформулированы гипотезы H0 и H1 для 15 числовых показателей.
*   Для каждого показателя проведен t-тест (с предварительной проверкой равенства дисперсий критерием Левена).
*   Выявлено, что статистически значимые различия присутствуют только по шкале «экстраверсия-интроверсия» (p < 0.05).
*   Проведено ранжирование показателей по силе различий (сортировка по p-value).
*   Выполнен этап Data Cleaning (обработка синтаксических ошибок в названиях столбцов).

### 3. ЛР 4-Бонус: Проверка на нормальность (Датасет «Iris»)
**Цель:** Освоить методы комплексной проверки на нормальность на классическом датасете цветов.
**Что сделано:**
*   Загружен и подготовлен датасет (удалены служебные столбцы, переименованы признаки, заданы индексы).
*   Адаптирована функция `Gauss` для проверки 4 показателей (длина/ширина лепестка и чашелистика).
*   Найден самый «ненормальный» показатель (с минимальным p-value).
*   Проведена проверка нормальности выбранного показателя отдельно по каждому из 3 сортов цветов.
*   Проведено сравнение распределения для «мелких» (Setosa) и «крупных» (Versicolor + Virginica) цветков.
